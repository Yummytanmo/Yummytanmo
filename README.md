Hi there! I'm **Wang Wenxuan**.

**🎓 About Me**
I'm a **Joint PhD Student** at **[HIT-SCIR](https://ir.hit.edu.cn/)** and **[Shanghai AI Lab](https://www.shlab.org.cn/)**, advised by **[Yu Cheng](https://ych133.github.io/)** and **[Weinan Zhang](https://homepage.hit.edu.cn/zhangweinan)**. I'm passionate about bridging the gap between deep learning research and real-world applications.

**🔭 Research**
My current obsession is **AI Agents**. I'm investigating how to build smarter, more robust agents that can handle long-horizon tasks. My work explores memory, planning, and learning from experience, as well as transferring agent experience into **generative models** and exploring how agents and generative models can improve together.

**📄 Selected Research**
* **[Internalizing Agent Experience into Diffusion Model Weights via On-Policy Context Distillation](https://arxiv.org/abs/2610.07250)** — arXiv preprint, 2026. [Code](https://github.com/Yummytanmo/D-OPCD-CoEvolution)

* **[Agent Planning Benchmark: A Diagnostic Framework for Planning Capabilities in LLM Agents](https://arxiv.org/abs/2606.04874)** — EMNLP 2026 Findings. [Code](https://github.com/Mikivishy/AgentPlanningBenchmark)
